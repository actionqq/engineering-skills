## 本轮修订

1. **对外接口兼容。** 上游 `codebase-design` 聚焦进程内模块，并将公共、跨团队接口导向 `api-design`。旧融合保留了前者，却没有接住这个分支。新增 [contracts.md](../skills/tech-design/references/contracts.md)，处理真实消费者、缺失与 null、枚举扩展、序列化、重试身份、权限和有界结果。保留明确授权的协调破坏性变更；拒绝上游“规则高于用户要求”以及一律只能追加的绝对化处理。
2. **运行边界与失败恢复。** 新增 [systems.md](../skills/tech-design/references/systems.md)，把架构推理延伸到进程、持久化、异步消息与外部副作用，逐个检查崩溃窗口、重试、取消、过载和恢复证据。这是依据已有依赖与 API 方法进行的综合工程补强，不假称某个上游已提供这一整套流程。
3. **实施中的数据迁移。** 新增 [evolution.md](../skills/implement/references/evolution.md)，融合渐进迁移和真实边界实验，再补入值级不变量、历史错误状态、批处理检查点、并发写入、混合版本与恢复边界。迁移实施不依赖另外安装 plan 或 prototype，也不默认授权生产执行。
4. **二分定位与完成自审。** [reproduction.md](../skills/diagnose/references/reproduction.md) 补回可比较 good/bad 边界、环境失败跳过、候选范围及因果确认；[implement](../skills/implement/SKILL.md) 明确测试之后还须检查实际成功与失败行为，自审不冒充独立评审。
5. **发现与验证定义。** 设计入口 description 明确设计／ADR 维护和接口演进；新增 5 个行为题、18 个发现请求（含此前文档能力的正例与相邻请求）。原有 46 个行为题和 64 个发现请求保持不变。

新增 API 来源仍固定在 citypaul 原有 commit；其来源说明记录了 Addy Osmani 的原始方法，但原始导入 commit 未知。保留该事实和原 MIT 声明，不伪造上游导入链。相关许可已纳入 tech-design 与 implement 的独立目录。

## 有意不扩大什么

没有新增 docs、API、migration、security 或 release 入口：本轮缺口是既有工作中的条件方法，已有清楚的落点。新增独立入口需要独立的用户任务、产物和足够的真实使用证据。专业安全审计、某项认证协议的完整设计、具体云平台发布和性能专项仍需按任务读取权威资料；这套通用工程 Skills 不冒充每个专科的完整手册。

没有照搬上游的自动提交、强制 issue tracker、每个小改动重新审批、固定数量代理／假设、三次修复失败即判架构错误。文档状态继续采用已确认的三个维度；上游约定之间的分歧由本集合明确决策，不堆叠互相冲突的命令。

## 验证与剩余缺口

9 个官方格式检查、集合引用闭包、能力与来源映射、80 个来源哈希以及 5 个新增原始用例导出通过。回填故障输入实际暴露了预期漏行，说明题目有实质判别点。[本地检查](../evals/source-audit-checks.json)、[结构检查](../evals/structural-results.json)。

这些检查不证明 Skill 带来能力增益。当前最需要补的是 **在新上下文中与默认模型、相关上游进行相同输入的行为比较**，尤其看是否真的读到条件参考、是否避免过度流程、是否正确修复中断回填。题库已准备，独立执行与宿主解析未运行；此前作者演练也没有因本轮改稿自动变成新版本通过记录。[完整状态](../evals/status.md)。
