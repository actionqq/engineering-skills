# Third-party notices

This Skill is an original synthesis for engineering-skills v0.2. It adapts methods and ideas rather than copying an upstream Skill verbatim.

Sources studied for the frontend method family include:

- Anthropic Claude Code `frontend-design` — distinctive visual direction and anti-template guidance.
- Paul Bakaus, `pbakaus/impeccable` — product-vs-brand register and frontend design lenses spanning hierarchy, interaction, responsive behavior, accessibility, UX writing, and polish.
- NextLevelBuilder, `ui-ux-pro-max-skill` — design-system and UI/UX knowledge organization, including product patterns, typography, palettes, accessibility, and technology-specific guidance.
- Taste Skill, `tasteskill/tasteskill` — anti-slop frontend heuristics for layout, typography, spacing, and motion.
- Vercel Labs, `web-interface-guidelines` — interaction, keyboard/focus, responsive, form, content, and interface-quality guidance.
- Matt Pocock, `skills/engineering/prototype` — prototype-as-evidence boundary and the distinction between experimental artifacts and production implementation.

The final instructions intentionally narrow the old generic prototype scope: business/domain modeling belongs to design work, while performance, persistence, concurrency, compatibility, and migration spikes remain engineering methods used where needed rather than responsibilities of this frontend prototype entry.
